# data/

Local working copies of datasets: university access logs, `ctpot_data.csv`, playground exports.

Everything in this folder except this README is git-ignored. Share data through an agreed,
access-controlled place (e.g. a UZH-provided drive), not through GitHub.

For each dataset, note in `docs/datasets.md` (no data, just metadata):
source, date obtained, who may use it, SHA-256 checksum, whether it contains raw IP addresses.
